## 설치 방법
1. 위의 **런처 다운로드** 버튼을 눌러 `NationWar-Setup.exe` 를 받습니다.
2. 받은 파일을 실행합니다.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누릅니다 (코드 서명이 없어서 뜨는 창입니다).
4. 설치가 끝나면 바탕화면의 **NationWar 런처** 로 켜고, 마이크로소프트 계정으로 로그인합니다.

## 업데이트
설치한 뒤에는 런처가 새 판을 스스로 받습니다. 새 판이 나오면 런처를 켤 때 업데이트 창이 뜨고, **[지금 업데이트]** 를 눌러야 런처를 쓸 수 있습니다.
